# irei — лаунчер для Android TV

Домашний экран для Android TV без рекламы и рекомендаций: только ваши приложения,
избранное, часы и шторка быстрых настроек.

## Установка

1. Скачайте `irei-launcher-….apk` из [последнего релиза](../../releases/latest).
2. Установите на приставку (через флешку и файловый менеджер, `adb install` или «Отправить файлы на ТВ»).
3. Нажмите «Домой» и выберите irei домашним экраном.

Новые версии лаунчер находит сам: ⚙ → «Настройки лаунчера» → «Обновление».

Исходный код в этом репозитории не публикуется.
